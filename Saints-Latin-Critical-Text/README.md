# Saints Latin Critical Text

- **Canonical Scope:** 70 books (43 OT + 27 NT) · 1,290 chapters · 34,446 verses
- **Method:** Reasoned eclecticism over open-licence Tiers 1–4 Vulgate, early pandect, and Old Latin witnesses (Tier 5 copyrighted Stuttgart/Weber–Gryson BSV and CC BY-NC-SA Vetus Latina MSS strictly excluded from this public edition).
- **Source Studio:** Generated by Saints Critical Text Studio (`01_Law/` through `07_Glory/`, synced 2026-11-21 to Studio v9 accuracy-audit edition).

## File Formats per Chapter
- `*_Critical_Text.md` — Four-section critical edition (Witness Declaration, Continuous Critical Text, Apparatus & Disregarded Noise Log, Verse-by-Verse Rationale).
- `*_Critical_Text.tsv` — Verse-level tabular critical text (`Book`, `Chapter`, `Verse`, `Critical_Text`, `Confidence`, `Substantive_Variants`, `Human_Locked`, `Analysis_Flags`).
- `*_Critical_Text.json` — Full structured collation, open-licence apparatus, and witness readings.
