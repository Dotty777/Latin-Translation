## Overview

This directory contains the **Saints Modern English** translation of the Latin Clementine Vulgate Old Testament, translated fresh from `Saints-Latin-Critical-Text` under the locked style policy ([`STYLE.md`](STYLE.md)) and shared term glossary ([`glossary.json`](glossary.json)).

- **Method:** Formal-equivalent (literal) Modern English smoothed for natural reading, with zero archaisms, strict Clementine Vulgate own-source fidelity (`Dominus` → `the Lord`, never harmonized to Greek/Hebrew), and original wording.
- **Related directories:** Complete 27/27 Latin NT in [`../Modern-English-NT/`](../Modern-English-NT/README.md); original reviewed pilot in [`../Modern-English-Pilot/`](../Modern-English-Pilot/README.md).
