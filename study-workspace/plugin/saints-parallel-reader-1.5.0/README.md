# Saints Parallel Reader

One home for the Parallel Reader's additions, kept as separate modules. The reader's table itself stays in Saints Study.

| Module | Replaces | Status |
|---|---|---|
| `modules/layout.php` | Saints Parallel Layout 1.0.1 | Included |
| `modules/verse-workspace/` | Saints Verse Workspace 0.1.0 | Included; administrators only, except on staging. Covers the Law, Salvation, Wisdom and Glory divisions (575 chapters) |
| `modules/latin-text.php` | New | Removes whole Latin verses from displayed pages |
| Highlights | Saints Parallel Reader Highlights 1.4.1 | Waiting for its source code |
| Word Notes | Saints Parallel Reader Word Notes 0.2.2 | Waiting for its source code |

## Switching over

Each module stays silent while the older plugin it replaces is active, so this plugin can be activated first without anything printing twice. Deactivating the older plugin hands the work to the module. Reactivating it hands the work back.

## Settings

- `SAINTS_PARALLEL_READER_LAYOUT_LIVE` in `modules/layout.php`: false shows the layout changes to administrators only.
- `SAINTS_PARALLEL_READER_WORKSPACE_LIVE` in `modules/verse-workspace/module.php`: false shows the panel to administrators only. Set it to true after the notes are reviewed. Sites on a `.wpcomstaging.com` address always show the panel to everyone, so the notes can be reviewed there.

## Verse Workspace data

Each chapter of Genesis–Deuteronomy, Matthew–John, Psalms, Proverbs, Ecclesiastes, Song of Songs, Lamentations, Wisdom of Solomon, Sirach and Revelation has two private records of the `saints_ws_chapter` type, served at `/wp-json/saints-workspace/v1/data/<name>`:

- `<book>-<chapter>`: readings, section headings, the source ratings for each verse and the word studies. Prose fields (overall message, Unseen Change, instructions, lexicon) are empty until written; the panel says so. `genesis-1` keeps the written Genesis 1 notes.
- `<book>-<chapter>-sources`: every source study the site holds for each verse, loaded when Unseen Change is opened. Sources: the Hebrew–Greek, Latin–Greek and King James–Greek comparisons the Parallel Reader links to, the Saints Translation notes, the Study Edition notes (Law and Wisdom) and the Disparate Studies (Law, Song of Songs), with the chapter notes.

Cross-references are built live from the cross-reference evidence and its reviews at `/wp-json/saints-workspace/v1/references/<book>-<chapter>` and cached for a day. Links not yet reviewed are shown in their own group with their evidence note.

The records are generated by `study-workspace/build_ws.py` in the Saints-Translation repository and installed by the staging helper.
