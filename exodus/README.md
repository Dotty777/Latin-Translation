- **Latin:** matches the Clementine Vulgate reference text in 1,211 of 1,213 readings (99.8%); the rest differ only by editorial labels or embedded translation notes (see [AUDIT.md](../AUDIT.md)).

- **Site review labels:** 0 readings still marked "review pending" / "assessment open"; 1,213 classified (Latin–Greek comparison: Same 468, Similar 414, Different 185, Divergent 138, Disparate 8).
- **Alignment:** each Latin reading sits on the reader row of the Saints verse its Greek pair is; where the Vulgate numbers the verse differently, `vulgate_reference` gives its own number (187 readings). Cards that cover several Vulgate verses are shown once, on their first row.
