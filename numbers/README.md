# Numbers — Latin–English (Clementine Vulgate)

36 chapters, 1,257 readings, captured from the Saints.Bible staging Parallel Reader on 2 November 2026. One of the 70 books of the [Latin–English column](../README.md); audit results in [AUDIT.md](../AUDIT.md).

- **Latin:** matches the Clementine Vulgate reference text in 1,256 of 1,257 readings (99.9%); the rest differ only by editorial labels or embedded translation notes (see [AUDIT.md](../AUDIT.md)).
- **English origin:** 1,151 fresh renderings; 13 Douay-Rheims verbatim; 93 Douay-Rheims lightly modernised; 0 with no Latin text.
- **Site review labels:** 0 readings still marked "review pending" / "assessment open"; 1,257 classified (Latin–Greek comparison: Same 567, Similar 501, Different 140, Divergent 43, Disparate 6).
- **Alignment:** each Latin reading sits on the reader row of the Saints verse its Greek pair is; where the Vulgate numbers the verse differently, `vulgate_reference` gives its own number (123 readings). Cards that cover several Vulgate verses are shown once, on their first row.
