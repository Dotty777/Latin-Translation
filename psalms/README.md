# Psalms — Latin–English (Clementine Vulgate)

150 chapters, 2,527 readings, captured from the Saints.Bible staging Parallel Reader on 2 November 2026. One of the 70 books of the [Latin–English column](../README.md); audit results in [AUDIT.md](../AUDIT.md).

- **Latin:** matches the Clementine Vulgate reference text in 2,510 of 2,527 readings (99.3%); the rest differ only by editorial labels or embedded translation notes (see [AUDIT.md](../AUDIT.md)).
- **English origin:** 2,354 fresh renderings; 12 Douay-Rheims verbatim; 161 Douay-Rheims lightly modernised; 0 with no Latin text.
- **Latin review (2 November 2026):** every reading with Latin was read against the Clementine Latin; 25 were corrected where the English departed from it (list in [corrections/2026-11-02-wisdom](../corrections/2026-11-02-wisdom/README.md)). Specialist sign-off is still pending.
- **Site review labels:** every Latin card now carries a Latin–Greek classification: Same 1,669, Similar 713, Different 103, Divergent 41, Disparate 1.
- **Verse numbering:** 80 readings carry a number that differs from the Vulgate's own (recorded as `vulgate_reference` in verses.json).
